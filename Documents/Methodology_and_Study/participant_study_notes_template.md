# Participant Study Notes Template

This is the **tracked reusable template**.

Actual participant-filled notes should go into the private companion file under:

- `Documents/Methodology_and_Study/Private/`

That private notes file is intentionally ignored by git.

This template exists to standardize what gets recorded during each session.

Its purpose is **not** to duplicate the Microsoft Forms response sheet.
Instead, it exists to capture:

- the quick pre-VR baseline check
- the refresher content actually delivered
- the instruction and mode path chosen for that participant
- live observation notes that do not naturally fit inside the questionnaire
- high-level comparative comments against traditional materials

The actual Section A/B/C/D form responses should still be treated as the primary recorded participant data.

## Baseline Questions

Use these **before** the refresher and **before** VR.
These were selected from the already approved question bank so no new instrument needs to be introduced.

### Q25. Which register stores the address of the next instruction?

- Stack Pointer
- Program Counter
- Instruction Register
- Base Register

### Q26. Which stage of the instruction cycle reads an instruction from memory?

- Decode
- Fetch
- Execute
- Write-back

### Q27. During instruction execution, the instruction register primarily stores:

- Program variables
- The currently executing instruction
- The stack pointer value
- Cache addresses

### Q28. What happens to the program counter after an instruction is fetched?

- It resets to zero
- It increments to the next instruction address
- It copies into the stack pointer
- It stores the result of the ALU

### Q39. Put the instruction stages in the correct order.

- Execute, Fetch, Decode, Write-back
- Fetch, Decode, Execute, Write-back
- Decode, Fetch, Execute, Write-back
- Fetch, Execute, Decode, Write-back
